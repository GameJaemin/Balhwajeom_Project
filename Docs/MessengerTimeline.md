# 메신저 날짜·시간 편집

Content Browser에서 `Content/Balhwajeom/Data/Messenger/Rooms`의 방 Data Asset을 연다.
`Messages` 배열의 각 항목에 있는 `SentAt`에서 작성 날짜와 시간을 입력한다.

- 예: 2026.05.12-18.30.00 → 오후 6:30
- 게임 속 현지 시각이며 PC 시간대에 따라 변환하지 않는다.
- 배열 순서가 대화 순서다. 자동 정렬하지 않으므로 앞 메시지보다 이른 시각을 입력하지 않는다.
- 첫 메시지와 날짜가 바뀌는 지점에 날짜·요일 구분선을 자동 표시한다.
- 날짜가 없는 메시지는 날짜 미상 / 시간 미상으로 표시하며 본문은 유지한다.
- 우클릭 데이터 검증으로 누락된 일시와 역순 입력을 확인한다.

기존 일시가 모두 비어 있는 방에는 마이그레이션 시 2026년 5월 12~13일의 예시 일시가 채워진다.
이는 임시 데이터이므로 기획 연표에 맞게 수정한다. 이미 입력된 일시는 덮어쓰지 않는다.

날짜 구분선은 읽지 않은 메시지 개수에 포함되지 않는다. 읽음 상태는 Data Asset 원본을 변경하지 않는다.
